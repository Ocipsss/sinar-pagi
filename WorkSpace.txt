Berdasarkan analisis file proyek Vue 3 / Dexie.js ini, terdapat beberapa fitur utama yang sudah masuk di dependencies atau database schema tetapi belum diimplementasikan dalam kode:
1. Fitur Cetak & Cetak Nota (Receipt Printing)
 * Problem: Dependency esc-pos-encoder dan jspdf sudah ada di package.json, serta pengaturan ukuran printer (58mm/80mm) ada di Settings.vue.
 * Kekurangan: Belum ada komponen, dialog, atau service untuk mencetak struk fisik via printer Bluetooth thermal maupun unduh nota PDF setelah transaksi di Kasir.vue.
2. Halaman Pengeluaran Operasional (Expenses)
 * Problem: File src/views/Expenses.vue masih kosong.
 * Kekurangan: Tabel db.expenses sudah didefinisikan di Dexie, tetapi belum ada antarmuka (UI), composable, maupun repositori untuk mencatat beban operasional toko (seperti listrik, sewa, plastik, dll.).
3. Autentikasi & Sesi Operator (Kasir Login)
 * Problem: Tabel dan tampilan Operators.vue sudah siap untuk input nama & PIN.
 * Kekurangan: Belum ada screen login/lock, route guard, atau penyimpanan sesi operator aktif. Kolom transaksi (transactions) juga belum menyimpan siapa operator yang memproses penjualan tersebut.
4. Notifikasi Toast (UI Notification)
 * Problem: Library vue-sonner sudah di-install.
 * Kekurangan: Aplikasi masih menggunakan alert() dan confirm() bawaan browser di berbagai komponen (useSettings, useCategories, kasirService, dll.), dan komponen <Toaster/> belum dipasang di MainLayout.vue atau App.vue.
5. Pembatalan Transaksi (Void) & Retur Penjualan
 * Problem: Riwayat penjualan (SalesHistory.vue) hanya menyajikan daftar transaksi.
 * Kekurangan: Belum ada logika untuk membatalkan nota (void), melakukan retur barang, atau mengembalikan saldo/stok barang yang batal dibeli.
6. Integrasi Kas Belanja Kulakan dengan Keuangan
 * Problem: Fitur Shopping.vue mendukung tombol centang item yang sudah dibeli (toggleBought).
 * Kekurangan: Saat status barang diubah menjadi "selesai dibeli", stok barang otomatis bertambah, tetapi tidak otomatis mencatat mutasi pengeluaran kas (OUT) pada sistem Finance.
7. PWA / Service Worker Setup
 * Problem: Plugin vite-plugin-pwa sudah terpasang di devDependencies.
 * Kekurangan: Konfigurasi PWA di vite.config.js dan registrasi service worker di main.js belum diterapkan agar aplikasi dapat di-install sebagai aplikasi desktop/mobile native yang responsif secara offline.
