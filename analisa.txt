🔴 3.3 Race Condition di syncService.js

```javascript
async pushLocalToCloud() {
  if (!navigator.onLine || isSyncing || !db || !firestore) { ... }
  isSyncing = true
  // ...
}
```

Masalah: isSyncing adalah variabel module-level, bukan reactive. Jika dua panggilan terjadi hampir bersamaan (mis. dari hook Dexie + interval 30 detik), yang kedua akan skip dan data tidak terkirim sampai interval berikutnya.

Rekomendasi: Gunakan queue atau debounce:

```javascript
let syncPromise = null
async pushLocalToCloud() {
  if (syncPromise) return syncPromise
  syncPromise = this._doPush().finally(() => { syncPromise = null })
  return syncPromise
}
```

🔴 5.1 vite.config.js Tidak Ada di Kode yang Dikirim

File vite.config.js tidak disertakan dalam src.txt. Ini penting untuk PWA — pastikan:

· VitePWA plugin terkonfigurasi
· registerType: 'autoUpdate'
· manifest lengkap (name, icons, theme_color)

```javascript
  plugins: [
    vue(),
    VitePWA({
      registerType: 'autoUpdate',
      includeAssets: ['favicon.ico', 'apple-touch-icon.png'],
      manifest: {
        name: 'Sinar Pagi POS',
        short_name: 'SinarPagi',
        theme_color: '#18181b',
        background_color: '#18181b',
        display: 'standalone',
        orientation: 'portrait',
        icons: [
          { src: 'pwa-192x192.png', sizes: '192x192', type: 'image/png' },
          { src: 'pwa-512x512.png', sizes: '512x512', type: 'image/png' }
        ]
      },
      workbox: {
        globPatterns: ['**/*.{js,css,html,ico,png,svg,woff2}'],
        runtimeCaching: [
          {
            urlPattern: /^https:\/\/firestore\.googleapis\.com\/.*/i,
            handler: 'NetworkFirst',
            options: { cacheName: 'firebase-cache', networkTimeoutSeconds: 5 }
          }
        ]
      }
    })
  ]
})
```

11. REKOMENDASI ARSITEKTUR JANGKA PANJANG

11.1 Pindah ke Event-Driven Sync

Daripada hook Dexie memanggil pushLocalToCloud langsung, gunakan event bus:

```javascript
// services/eventBus.js
import { reactive } from 'vue'
export const eventBus = reactive({ events: [] })
export const emit = (event, payload) => {
  eventBus.events.push({ event, payload, ts: Date.now() })
}

// Di hook Dexie:
emit('db:change', { table: table.name, id: primKey })

// Di syncService:
watch(() => eventBus.events.length, () => {
  debouncedPush()
})
```

11.2 Tambah State Machine untuk Sync

```
IDLE → SYNCING → SUCCESS/ERROR → IDLE
```

Dengan timeout dan retry exponential backoff.

11.3 Gunakan Web Worker untuk Sync

Agar UI tidak block saat sync data besar:

```javascript
// workers/syncWorker.js
self.onmessage = async (e) => {
  const { action } = e.data
  if (action === 'push') await pushToCloud()
}
```

11.4 Tambah Fitur "Mode Demo"

Untuk testing tanpa Firebase:

```javascript
// services/firebase.js
export const firestore = import.meta.env.VITE_DEMO_MODE === 'true' 
  ? null 
  : getFirestore(app)
```
